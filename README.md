# 高标准农田「一张图」演示系统

县域高标准农田上图核查的可视化演示系统：地图上展示项目区与地块图斑，联动统计面板查看建设面积、投资与进度。

> **演示数据说明**：仓库内全部地块与项目区数据均为**虚构/示意数据**，不使用任何真实图斑与业务数据，可自由运行与二次开发。

## 技术栈

- Vue 3（Composition API）+ Vite 5
- OpenLayers 10（地图渲染、图层控制、要素高亮）
- Element Plus（面板与表单组件）
- ECharts 5（面积/投资统计图表）

## 功能

1. 底图切换（影像 / 矢量），地图缩放与视野约束
2. 项目区面要素渲染，按建设状态分级配色
3. 点击图斑联动右侧统计面板（面积、投资额、建设年度）
4. 按乡镇 / 年度 / 状态组合筛选，地图与图表同步刷新
5. 图层显隐控制与图例

## 本地运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
```

## 目录结构

```
src/
├── api/           # 数据接口（本仓库为本地模拟数据）
├── components/    # MapView 地图容器、StatsPanel 统计面板
├── data/          # baseMaps 底图配置、parcels 示意地块数据
├── App.vue
└── main.js
```

## 说明

本项目为个人技术演示，用于验证「政务/水利类 GIS 一张图」的前端实现路径。真实项目中的业务数据、图层服务与权限体系未包含在内。
